## Mục tiêu

Gỡ toàn bộ cơ chế ngưỡng: ingest không còn tự pause, không còn gửi Web Push, không còn `OPENCODE_CYCLE_TOKEN_LIMIT`/ước lượng % từ token OpenCode. Giữ nút pause thủ công (`POST /api/control` với `global_status`) và `hooks/claude-code/circuit-breaker.sh`. Plugin OpenCode chỉ còn gửi token mỗi message vào danh sách agent (telemetry).

## Ý tưởng
- Backend: `processIngest` chỉ ghi log + cập nhật snapshot, trả `{ global_status }`; `Control`/`ControlPatch` chỉ còn `global_status`; gỡ `api/subscribe.ts`, `api/_lib/push.ts`, dependency `web-push`.
- Dashboard: Circuit Breaker chỉ còn nút RUNNING/PAUSED; gỡ ô ngưỡng + "Lưu", banner push, `public/push-sw.js`, dòng "Time to limit" (chỉ dựa vào cycle limit OpenCode).
- Plugin OpenCode: gỡ backfill (bun:sqlite + state file) và `cycle_token_limit`; chỉ còn `message.updated` → POST delta.
- Không viết migration: các cột/bảng cũ (`auto_pause_threshold`, `downgrade_model_threshold`, `cycle_token_limit`, `push_subscriptions`) để nguyên trong DB, code chỉ ngừng dùng.

## Quyết định đã chốt
- Không thêm migration, không đụng DB schema (cột/bảng cũ thành "chết", ghi vào README).
- Giữ `QuotaSnapshot.cycle_tokens_used`/`cycle_token_limit` trong type (cột vẫn tồn tại, `rowToSnapshot` vẫn map); RPC `increment_opencode_usage` vẫn được gọi, chỉ truyền `p_limit: null`.
- Giữ PWA shell (manifest + SW do workbox sinh, `registerSW`), chỉ bỏ phần push.
- Giữ `createReadOnlyControlApi` ở live mode (ghi control qua dashboard vẫn là việc sau, không thuộc task này).
- Response `POST /api/ingest` còn `{ ok: true, global_status }` (bỏ `paused_now`; không hook nào đọc nó). `GET /api/status` trả `{ global_status, snapshots }` (`circuit-breaker.sh` chỉ đọc `.global_status`).
